# BalancedGaming

A Windows desktop application developed as part of an Honours Project at Glasgow Caledonian University (2025-2026).

## About
BalancedGaming helps adult gamers track their gaming sessions and monitor how gaming affects their psychological well-being over time. Users can log sessions, 
complete mood assessments before and after play, view trends on a dashboard, and set break reminders.

## Features
- Session tracking with start/stop timer
- Multi-dimensional mood assessment (mood, stress, energy) before and after each session
- Dashboard with weekly gaming charts and mood comparison graphs
- Configurable break reminders with game exceptions
- Steam library integration
- CSV export of session data

## Technologies Used
- C# / .NET
- Windows Presentation Foundation (WPF)
- SQLite with Entity Framework Core
- LiveChartsCore
- Steam Web API

## How to Run
1. Clone the repository
2. Open in Visual Studio 2022
3. Restore NuGet packages
4. Build and run the project
